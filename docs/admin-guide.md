# Инструкция для админа

Админ в боте - это мастер, который ведет свое расписание: задает рабочие дни, часы, длительность сеанса, создает свободные места, записывает клиентов вручную и управляет переносами.

## 1. Первый вход

Откройте бота в Telegram и напишите:

```text
/start
```

Бот покажет вашу роль. Должно быть:

```text
Ваша роль: админ
```

Если роль `клиент`, значит супер админ еще не назначил вас админом.

Супер админ должен написать:

```text
/admin_add @ваш_username
```

или:

```text
/role @ваш_username admin
```

## 2. Выбор языка

Русский:

```text
/lang ru
```

Английский:

```text
/lang en
```

После этого бот будет отвечать на выбранном языке.

## 3. Заполнить информацию о себе

Профиль мастера, произвольный текст:

```text
/setprofile Мастер маникюра. Работаю в центре города. Адрес: ...
```

Услуги и цены:

```text
/setservices Маникюр 40€, педикюр 50€, покрытие 10€
```

Это нужно, чтобы клиентам можно было показывать информацию о мастере и услугах.

## 3.1. Добавить услуги с длительностью

Каждая услуга должна иметь свою длительность. Клиент сможет выбрать одну или несколько услуг, а бот сам посчитает общую длительность.

Добавить услугу на 30 минут:

```text
/service_add 30 Маникюр
```

Добавить услугу на 45 минут:

```text
/service_add 45 Покрытие
```

Посмотреть список своих услуг:

```text
/services
```

Клиент увидит услуги с номерами. Например:

```text
1. Маникюр - 30 мин.
2. Покрытие - 45 мин.
```

Если клиент выберет обе услуги:

```text
/schedule 1 2
```

Бот покажет только свободные интервалы на `75 минут`.

## 4. Настроить рабочее время

Укажите дни и часы работы:

```text
/sethours пн-пт 10:00-18:00
```

Примеры:

```text
/sethours пн-сб 09:00-19:00
```

```text
/sethours вт,чт,сб 12:00-20:00
```

Можно использовать русские дни:

```text
пн вт ср чт пт сб вс
```

Или английские:

```text
mon tue wed thu fri sat sun
```

## 5. Настроить длительность сеанса

Это базовый шаг расписания, из которого бот собирает длинные записи под услуги.

Для услуг разной длительности лучше использовать 15 или 30 минут.

```text
/setduration 15
```

Если все услуги кратны 30 минутам, можно использовать:

```text
/setduration 30
```

## 6. Создать расписание на месяц

После настройки `/sethours` и `/setduration` создайте свободные места:

```text
/generate 2026-06
```

Это создаст расписание на июнь 2026.

Повторный запуск безопасен:

```text
/generate 2026-06
```

Бот не создаст дубликаты. Уже существующие слоты будут пропущены.

## 7. Посмотреть свободное время

```text
/schedule
```

Бот покажет свободные места с номерами:

```text
1. 2026-06-01 10:00
2. 2026-06-01 11:00
3. 2026-06-01 12:00
```

Для конкретного месяца:

```text
/schedule 2026-06
```

## 8. Записать клиента вручную

Если клиент написал вам лично, вы можете записать его сами:

```text
/appoint @client_username 2026-06-01 14:00
```

С указанием времени в пути клиента:

```text
/appoint @client_username 2026-06-01 14:00 45
```

Где `45` - это минуты в пути.

Если время в пути не указать, будет использовано значение по умолчанию: `30 минут`.

## 9. Отменить запись клиента

```text
/cancel @client_username 2026-06-01 14:00
```

После этого слот снова станет доступен.

## 10. Перенести запись клиента

```text
/reschedule @client_username 2026-06-01 14:00 2026-06-03 16:00
```

Формат:

```text
/reschedule @клиент старая_дата старое_время новая_дата новое_время
```

## 11. Заблокировать время

Если вы не хотите принимать запись на конкретное время:

```text
/block 2026-06-01 15:00
```

Например, если у вас личное дело, перерыв или уже есть запись вне Telegram.

## 12. Как клиент записывается сам

Клиент пишет:

```text
/schedule
```

Бот показывает свободные места:

```text
1. 2026-06-01 10:00
2. 2026-06-01 11:00
```

Клиент выбирает номер:

```text
/book 2
```

После этого запись создается автоматически.

## 13. Как клиент переносит запись сам

Клиент пишет:

```text
/my
```

Бот показывает его записи:

```text
1. 2026-06-01 11:00
```

Потом клиент открывает свободные места:

```text
/schedule
```

И переносит запись:

```text
/move 1 3
```

Это значит: перенести запись номер `1` на свободное место номер `3`.

Админу приходит уведомление, что клиент перенес запись.

## 14. Напоминания

Бот отправляет напоминания автоматически:

- за день до записи клиенту;
- за день до записи админу;
- в день записи клиенту за `время в пути + 10 минут`.

Пример: если клиент указал `30 минут` в пути, бот напомнит за `40 минут` до записи.

## 15. Основной рабочий сценарий админа

Один раз настроить профиль:

```text
/setprofile ...
```

Один раз настроить услуги:

```text
/setservices ...
```

В начале месяца задать график:

```text
/sethours пн-пт 10:00-18:00
```

Задать длительность сеанса:

```text
/setduration 60
```

Создать расписание:

```text
/generate 2026-06
```

Дальше клиенты сами смотрят `/services`, выбирают услуги, открывают `/schedule 1 2` и записываются через `/book номер`.
